# Map Note
Note Map allows users to create and view notes linked to different geographic locations on an interactive map.

# Features
- Location-Based Notes: Add notes tied to specific locations on the map.
- Geolocation Integration: Automatically detect and display the user's location.
- Custom Note Creation: Dynamically create, edit, and delete notes.
- Responsive Design: Optimized for both desktop and mobile devices.
- Real-Time Map Updates: Instantly display notes on the map.
# Technologies Used
- HTML5
- CSS3
- JavaScript
- Geolocation API
